IZAM WAHYU FADHILA (21)

Tampilkan perhitungan ⌄

permisalan

  • x = harga 1 jam dinding
  • y = harga 1 tas anyaman

Permodelan

x + 2y = 200.00
3x + 5y = 520.000

Penyelesaian

  1. Eliminasi nilai x:
    x + 2y = 200.000 | x5
    2x + 3y = 520.000 | x2
    5x + 10y = 1.000.000
    6x + 10y = 1.040.000_
     -x = -40.000
    x = 40.000
    x =Rp40.000
  2. Substitusi nilai y ke Paket 1:
    x + 2y = 200.000
    x(40.000) + 2y = 200.000
    40.000 + 2y = 200.000
    2y = 200.000 - 40.000
    y = 160.000
     2
     y = Rp80.000
Hasil: x(harga 1 jam dinding)=Rp40.000, y(harga 1 tas anyam)=Rp80.000

MELINDA IKA SETYAWATI (25)

Tampilkan perhitungan ⌄

Permisalan

  • x = harga 1 tempat sampah
  • y = Harga 1 rak buku

    • Permodelan

    x + 2y = 440.000
    2x + y = 595.000

    Penyelesaian

  • Eliminasi nilai x:
    x + 2y = 440.000|x1
    2x + y = 595.000|x2
    x + 2y = 440.000
    4x + 2y = 1.190.000-
     -3x = -750.000
    x = -750.000
    -3
    x = 250.000
    → x = Rp250.000
  • Substitusi nilai y ke Paket 1:
    x + 2y = 440.000
    250.000 + 2y = 440.000
    2y = 440.000 - 250.000
    2y = 190.000
    y = 190.000
    2
    → y = Rp95.000
    • Hasil: x(harga 1 tempat sampah)=Rp250.000, y(harga 1 rak buku)=Rp95.000

OKTAVIANI CAYSARA HANDAYANI (34)

permisalan

  • x = harga 1 robot
  • y = harga 1 rak buku

Permodelan

x + 2y = 290.000
2x + y = 295.000

Penyelesaian

  • Eliminasi nilai x:
    x + 2y= 290.000 |x1
    2x + y = 295.000|x2
     x + 2y =290.000
    4x + 2y =590.000-
     -3x = -300.000
    x = -300.000
    -3
    x = 100.000
    x = Rp100.000
  • Substitusi nilai y ke Paket 2:
    x + 2y = 290.000
    100.000 + 2y = 290.00
    2y = 290.000 - 100.00
    y = 190.000
     2
    y = Rp95.000
    • Hasil: x(harga 1 robot)=Rp100.000, dan y(harga 1 rak buku)=Rp95.000
